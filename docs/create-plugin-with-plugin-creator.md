# Plugin Creator で「登山計画」プラグインを作成する

Web 版 ChatGPT の Plugin Creator に、このリポジトリの3ファイルと作成プロンプトを渡し、「登山計画」プラグインを作成する手順です。作成後は、保存された指示・参照資料を確認し、新しい会話で試用します。

## 1. 利用環境を確認する

Web 版 ChatGPT で、利用するアカウント・ワークスペースを選択します。Plugin Creator が利用可能で、プラグインの使用・作成が許可されている必要があります。表示されない場合は、ワークスペースの設定や管理者への確認が必要です。作成と編集の基本操作は、[OpenAI 公式「Build plugins」](https://learn.chatgpt.com/docs/build-plugins)を参照してください。

今回作成するのは、スキルと参照資料を同梱するプラグインです。最新情報の取得には、実行する ChatGPT 環境の Web 検索・資料閲覧機能を使います。この構成自体には検索ツールや気象・交通 API を含めません。スキルとデータ取得機能の役割は、[OpenAI 公式「Skills」](https://developers.openai.com/plugins/concepts/skills)でも説明されています。

## 2. 添付する3ファイルを準備する

以下のリンク先のファイルを、Plugin Creator との会話に添付できるように用意します。

| 添付ファイル | このリポジトリのファイル | 役割 |
| --- | --- | --- |
| `SKILL.md` | [plugin/skills/mountaineering-plan/SKILL.md](../plugin/skills/mountaineering-plan/SKILL.md) | 適用条件、基本指示の読み込み、質問に応じた詳細資料の参照方法 |
| `project-instructions.md` | [project-instructions.md](../plugin/skills/mountaineering-plan/references/project-instructions.md) | スキル使用時に適用する基本指示 |
| `mountaineering-plan.md` | [mountaineering-plan.md](../plugin/skills/mountaineering-plan/references/mountaineering-plan.md) | 分野別の判断手順、全節と付録を含む詳細資料 |

リポジトリをダウンロードした場合は、表のパスにある実ファイルを選択します。ブラウザーで GitHub から取得する場合は、各ファイルの Raw 表示などから本文を保存し、HTML ページを添付しないようにします。

`SKILL.md` は `references/` 内の2ファイルを参照します。作成時に Plugin Creator が実際の同梱先に合わせて参照を整えるため、添付段階では3ファイルを個別に渡せます。詳細資料を要約版に置き換えず、全節と付録を含むファイルを添付してください。

## 3. Plugin Creator を選択して作成を依頼する

1. Web 版 ChatGPT で新しい会話を開きます。
2. 入力欄で `@` を入力し、候補から **Plugin Creator** を選択します。
3. 前節の3ファイルを添付します。
4. 以下の作成プロンプトを貼り付けて送信します。

この操作は、[OpenAI 公式の作成手順](https://learn.chatgpt.com/docs/build-plugins)に沿っています。`@Plugin Creator` は候補から選択し、プラグインが選択された状態で送信してください。

### 作成プロンプト

```text
添付した3ファイルを使って、Web版ChatGPTで利用する「登山計画」プラグインを作成してください。

目的：
山岳気象、登山ルート、公共交通、現地状況を統合し、
登山口へのアクセスから安全な下山・帰宅までの計画を支援します。

添付ファイルの役割：
- SKILL.md：スキルの適用条件と資料の参照方法
- project-instructions.md：スキル使用時に適用する基本指示
- mountaineering-plan.md：必要な節を参照する詳細資料

基本指示と詳細資料はスキルの references/ に同梱し、
スキル使用時に直接読み込んでください。
SKILL.md の参照先を、実際に同梱する資料に合わせてください。
詳細資料の全節と付録を保持してください。

入力：
山行日、山・ルート、出発地、交通手段、登山経験、
携行装備、帰宅希望時刻。

回答：
日本語で結論を先に示してください。
総合計画では ACCESS・TRAIL・WEATHER・RETURN・MARGIN を評価し、
行程、撤退時刻、最終交通までの余裕、代替案を示してください。
個別質問では必要な分野に絞ってください。

最新情報は利用可能なWeb検索・公式資料の閲覧で確認し、
出典と対象・更新・確認日時を示してください。
検索できない場合や重要情報が不足する場合は、その旨を明示し、
未確認情報を確認済みとして扱わないでください。

まず自分で試せる状態まで作成し、
保存された指示と参照資料を確認できるようにしてください。
```

## 4. 作成と保存を完了する

Plugin Creator の案内に従い、名前・説明・同梱資料を確認して保存まで進めます。追加で構成を聞かれた場合は、今回の用途を次のように伝えます。

```text
今回は、スキルと同梱参照資料を使う構成にしてください。
プラグインと登山計画用スキルの表示名は、両方とも「登山計画」にしてください。
内部名は mountaineering-plan にそろえてください。
最新情報は、利用環境にある Web 検索・資料閲覧機能で確認します。
```

保存後は、作成されたプラグインへのリンクを開き、名前と内容を確認します。ZIP の生成や指示案の提示までで止まっている場合は、アカウントへの保存を依頼します。保存機能が利用できないと説明された場合は、作成物を保管し、保存待ちとして扱います。

新規ワークスペースプラグインは、共有前に試用できる非公開の状態から始まります。保存後にインストールを求められた場合は、案内に従ってインストールします。[作成・試用の公式ガイド](https://learn.chatgpt.com/docs/build-plugins)

## 5. 保存された指示と参照資料を確認する

作成時の説明に加えて、保存済みプラグインのファイルを確認します。Plugin Creator に、次のように依頼してください。

```text
作成した「登山計画」プラグインの保存済みファイルを読み直してください。
作成案ではなく、保存されている内容を確認したいです。

次を表示してください。
1. プラグインへのリンク、内部名、バージョン
2. 同梱ファイルの一覧とパス
3. 保存された SKILL.md の全文
4. 保存された project-instructions.md の全文
5. 保存された mountaineering-plan.md の節・付録の見出し一覧

SKILL.md のリンク先に資料が存在し、基本指示が使用時に読み込まれること、
基本指示と詳細資料がスキルから直接読み込まれること、
詳細資料の全節と付録が添付原本から欠落していないことを確認してください。
確認できない項目は未確認としてください。
```

このリポジトリの構成を使う場合、確認するファイルは次のとおりです。Plugin Creator が異なる配置を採用した場合は、保存済みの一覧で実際のパスを確認します。

```text
skills/mountaineering-plan/
├── SKILL.md
├── agents/openai.yaml
└── references/
    ├── project-instructions.md
    └── mountaineering-plan.md
```

確認する点は次のとおりです。

- `SKILL.md` に、基本指示を最初に読み、詳細資料の必要な節を参照する手順がある。
- `SKILL.md` の相対リンク先に、2つの参照資料が保存されている。
- 詳細資料に §0〜§87、付録A、付録B がある。見出しだけでなく本文も保持されている。
- 日本語・結論先行、5条件の評価、個別質問の範囲、未確認情報の扱いが保存されている。
- プラグインとスキルの表示名が「登山計画」になっている。

見出し一覧だけでは本文の完全性まで確認できません。全文表示やアーカイブの取得を依頼し、詳細資料を添付原本と比較してください。参照パスを調整した場合は、その変更箇所と本文の欠落がないことを分けて確認します。スキルから補助資料を参照する構成は、[OpenAI 公式「Build skills」](https://developers.openai.com/plugins/build/skills)に沿っています。

## 6. 新しい会話で試す

新しい会話を開き、`@` メニューの Plugins から **登山計画** を選択します。元の3ファイルを再添付せずに試し、作成用の会話だけに依存していないことを確認します。インストール方法は、[OpenAI 公式「Plugins」](https://learn.chatgpt.com/docs/plugins)を参照してください。

### 総合計画を試す

以下の角括弧内を、実際の山行条件に置き換えます。

```text
[YYYY-MM-DD] に [山名] への日帰り登山を検討しています。

- 希望ルート：[登山口・経由地]
- 出発地：[最寄り駅など]
- 交通手段：[公共交通など]
- 登山経験：[季節・地形、最近の山行と所要時間]
- 携行装備：[今回持っていく装備]
- 帰宅希望時刻：[時刻]

登山口へのアクセスから下山・帰宅まで計画してください。
行程、制約ごとの撤退時刻、最終交通までの余裕、代替案を示してください。
最新情報の出典と対象・更新・確認日時を示し、未確認事項を区別してください。
```

日本語で結論が先に示され、ACCESS・TRAIL・WEATHER・RETURN・MARGIN の評価と、その根拠があるかを確認します。時刻計算では、登山口から乗り場までの移動、休憩、乗車準備、安全余裕が考慮され、同じ余裕を重複して計上していないかも確認してください。

### 個別質問と不足情報を試す

| 試す条件 | 質問例 | 確認する振る舞い |
| --- | --- | --- |
| 交通だけ | `[日付] に [出発駅] から [登山口] へ公共交通で行く場合、登山開始は何時になりますか。今回は往路交通だけ確認してください。` | 交通に絞り、未調査の気象・登山道まで含めた登山可否を断定しない |
| 日付不足 | `[山名] に公共交通で日帰りしたいです。` | 山行日など重要な不足情報を確認し、日付を勝手に確定しない |
| 検索しない条件 | `動作確認です。今回は Web 検索・外部資料の閲覧を使わず、[日付] の [山名] の計画に必要な確認事項を整理してください。` | 最新情報を確認済みにせず、成立性を左右する情報が不足すれば PENDING とする |

「検索しない条件」は未確認情報の扱いを試すためのものです。実際に検索機能が利用できない環境の確認とは区別します。最新情報を調べる試用も行い、出典と対象・更新・確認日時が示されるか、取得できない情報は未確認とされるかを確認してください。出典に更新日時が記載されていない場合、推測で埋めないことも確認します。

さらに、[詳細資料の付録A・B](../plugin/skills/mountaineering-plan/references/mountaineering-plan.md#付録a境界条件の回答例)に沿って境界条件と回答前の確認項目を試せます。作成・保存の成功と、実際の回答品質の確認は別です。

## 7. 修正・資料更新を反映する

**Plugins → 対象プラグイン → Edit Plugin** を開き、更新内容を伝えます。これは[公式の編集手順](https://learn.chatgpt.com/docs/build-plugins)に沿った操作です。

資料を更新する場合は、変更したファイルを添付し、次のように依頼します。

```text
既存の「登山計画」プラグインを更新してください。
添付したファイルで、対応する同梱資料を差し替えてください。
参照先が変わる場合は SKILL.md も更新し、詳細資料の全節と付録を保持してください。
プラグインとスキルの表示名「登山計画」、5条件の評価、
個別質問では必要な分野に絞ること、未確認情報を確認済みにしないことを保持してください。
保存後、変更したファイルと参照先、バージョンを示してください。
```

ローカルファイルの変更は、Plugin Creator で保存したプラグインには自動反映されません。原本は `plugin/skills/mountaineering-plan/` 内で管理し、変更したファイルを添付して反映します。更新後は保存済みファイルを再確認し、新しい会話で同じ質問を試してください。ローカル用プラグインの更新方法は、[plugin/README.md](../plugin/README.md#資料を更新する)にあります。

## 困ったとき

| 状況 | 確認・対応 |
| --- | --- |
| Plugin Creator が候補にない | 利用中のアカウント・ワークスペースと、Plugin Creator の提供・使用権限を確認する |
| 保存した「登山計画」が候補にない | 作成先のアカウント・ワークスペース、保存完了、インストール状態を確認して新しい会話で試す |
| 表示名が内部名になっている | Edit Plugin で表示名の修正を依頼する。必要に応じて [agents/openai.yaml](../plugin/skills/mountaineering-plan/agents/openai.yaml) を添付する |
| 基本指示や詳細資料を読めない | 保存済み一覧と `SKILL.md` の参照パスを照合し、欠落ファイルの同梱やリンク修正を依頼する |
| 新しい会話で資料の再添付を求められる | 作成時の添付だけでなく、プラグインの参照資料として保存されているか確認する |
| 最新情報を確認できない | 利用環境の検索・閲覧機能を確認する。取得できない情報は未確認とし、重要な不足があれば判定を保留する |
